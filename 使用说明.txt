数据查询系统 - Python版
========================

【软件功能】
本软件用于连接 Access 数据库（.mdb/.accdb）或 SQL Server 数据库，
进行数据查询、编辑、撤回和导出操作。

【系统要求】
- Windows 7 SP1（需安装 KB2533623 更新）/ Windows 8/10/11 操作系统
- 已安装 Microsoft Access 数据库引擎（连接Access数据库时需要）
- 已安装 ODBC Driver 17 for SQL Server（连接SQL Server时需要）

【使用方法】

1. 启动软件
   - Windows 7 用户：双击 "数据查询系统-Win7.exe"
   - Windows 10/11 用户：双击 "数据查询系统.exe"
   无需安装Python环境即可运行。

2. 连接数据库
   - Access数据库：点击"选择数据库"按钮，选择 .mdb 或 .accdb 文件
   - SQL Server：点击"SQL Server"按钮，输入服务器地址和数据库名称

3. 查询数据
   - 在"数据表"下拉框选择要查询的表
   - （可选）输入"关键词"在所有字段中搜索
   - （可选）选择"字段"并输入"字段值"进行精确搜索
   - 设置"最多"显示条数（默认1000条）
   - 点击"查询"按钮

4. 编辑数据
   - 双击表格中的单元格，自动填充列名和当前值
   - 在"列名"和"新值"输入框中修改内容
   - 点击"应用修改"按钮
   - 如需撤销，点击"撤回"按钮
   - 确认无误后，点击"保存到数据库"按钮将修改写入数据库

5. 导出数据
   - 点击"导出CSV"按钮，选择保存位置
   - 查询结果将保存为CSV文件

【注意事项】
- 编辑数据后必须点击"保存到数据库"才会真正修改数据库中的数据
- 修改前建议先备份数据库
- 如遇到连接问题，请检查是否安装了相应的数据库驱动程序
